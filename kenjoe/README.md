# KenJoe Operating System

A custom operating system project built from the ground up.

## Overview
This project implements a basic operating system with core kernel functionality, bootloader, and system utilities.

## Directory Structure
- `bootloader/` - Boot loader code
- `kernel/` - Core kernel implementation
- `drivers/` - Hardware drivers
- `utils/` - System utilities
- `build/` - Build artifacts

## Building
```bash
make build
```

## Running
```bash
make run
```
